Clock Generators

Programmable and multi-output timing devices for systems needing more than one clock.

A clock generator takes one reference input and produces the several clock outputs a system needs, usually through a phase locked loop with programmable dividers. It removes the need for a separate oscillator per frequency, which saves board space, cost, and part count.

Programmable devices allow output frequencies to be configured rather than fixed at manufacture, which is useful across product variants. Where electromagnetic emissions are a concern, spread spectrum modulation deliberately smears the clock energy across a small band to reduce measured peaks.

What buyers usually specify

  • Number of outputs, and the frequency required from each
  • Input reference: crystal, external clock, or both
  • Jitter performance, which matters most for high speed serial links
  • Output logic standard for each bank
  • Configuration method, and whether settings persist without a host
